## 프로젝트 개요

- **주제**: 미정 (자유 주제 — 실생활 문제 해결, 데이터 수집·분석·시각화, 텍스트/GUI 게임, 업무 자동화 등)
- **필수 요소**
  - 파이썬 기본 문법: 기본 자료형·자료구조(리스트, 딕셔너리 등), 조건문, 반복문, 함수 정의 및 **클래스 적용**
  - 파이썬 확장 활용 (**택 1 이상**)
    - [ ] 공공데이터/오픈 API 연동 (`requests` 등)
    - [ ] 데이터 분석 및 시각화 (`pandas`, `matplotlib` 등)
    - [ ] 파일 처리 또는 경량 DB 연동 (CSV, JSON, `sqlite3` 등)
    - [ ] 대화형/시각적 인터페이스 (Streamlit, tkinter, turtle 등)
- **파이썬 제출 형태**: 파이썬 **소스코드**(`.py` / `.ipynb`) 또는 **Streamlit** 앱
