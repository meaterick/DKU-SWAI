# DKU-SWAI — Kaggle 폐암 설문 데이터 기반 분류 모델

단국대학교 **SW·AI입문(SW) 2차 팀 프로젝트**입니다. Kaggle의 폐암 설문 데이터에 있는 나이, 생활 습관, 증상 항목을 이용해 `LUNG_CANCER`(YES/NO)를 분류하는 모델을 만들고 평가합니다. 4조는 예외적으로 3인 1조이며, 프로그램 구현·구조 설계·자료 조사와 발표 준비를 나누어 진행합니다. 제출 보고서에는 각자의 실제 수행 작업을 구체적으로 기록합니다.

> 이 프로젝트는 수업용 데이터 분석 실습입니다. 모델 출력은 실제 폐암 진단이나 의료 판단에 사용할 수 없습니다.

## 현재 구현과 개발 계획

1. CSV의 필수 열과 값 범위를 확인하고 완전히 동일한 행을 제거합니다.
2. 설문 응답을 숫자로 변환하고 정답 비율을 유지해 학습·평가 데이터를 80:20으로 나눕니다.
3. 학습 데이터로만 스케일러를 적합한 뒤, 클래스 불균형을 고려한 로지스틱 회귀 기준 모델을 학습합니다.
4. 보류한 평가 데이터에서 정확도, YES 클래스 정밀도·재현율·F1, ROC AUC, 혼동 행렬을 기록합니다.

현재는 기준 모델 코드와 실행 절차를 준비했습니다. 실제 데이터로 학습한 점수는 아직 게시하지 않았습니다. 다음 작업은 원본 CSV의 품질과 클래스 분포 확인, 탐색적 시각화, 모델 비교, 결과 기록, 시연 방식 결정입니다. 작은 설문 데이터의 단일 분할 점수만으로 일반화 성능이나 임상적 효용을 주장하지 않습니다.

## 데이터 준비

- **출처:** [Kaggle — Lung Cancer (mysarahmadbhat)](https://www.kaggle.com/datasets/mysarahmadbhat/lung-cancer)
- **정답 열:** `LUNG_CANCER` (`YES`/`NO`)
- **기본 정보:** `GENDER` (`F`/`M`), `AGE` (1~120 사이 숫자)
- **설문 항목:** `SMOKING`, `YELLOW_FINGERS`, `ANXIETY`, `PEER_PRESSURE`, `CHRONIC DISEASE`, `FATIGUE`, `ALLERGY`, `WHEEZING`, `ALCOHOL CONSUMING`, `COUGHING`, `SHORTNESS OF BREATH`, `SWALLOWING DIFFICULTY`, `CHEST PAIN` (각각 1=아니오, 2=예)

Kaggle에서 설문 CSV를 직접 내려받아 `data/survey_lung_cancer.csv`로 저장합니다. 원본 파일명이 다르면 이름을 바꾸거나 실행 시 `--data`에 경로를 지정합니다. CSV는 Git에서 제외합니다. 다운로드 전에 Kaggle 페이지의 데이터 사용 조건을 확인하고, 실제 제출물에는 사용한 데이터셋 버전과 다운로드 날짜를 적습니다. 열 이름의 앞뒤 공백은 코드가 제거하지만, 다른 버전의 데이터라면 열과 인코딩을 먼저 확인해야 합니다.

## 실행 방법

Python 3.10 이상을 권장합니다. 저장소 루트에서 실행합니다.

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python src/train.py --data data/survey_lung_cancer.csv
```

`src/train.py`는 설문 CSV를 검증하고 학습·평가합니다. 실행 결과는 `artifacts/metrics.json`과 `artifacts/model.joblib`에 저장됩니다. 입력에 필수 열이 없거나 값 인코딩이 다르면 오류를 냅니다. 평가 점수는 한 번 분할한 테스트 데이터의 결과입니다.

- **기본 문법:** 기본 자료형·자료구조, 조건문, 반복문, 함수와 클래스 적용이 필요합니다. 현재 코드에는 함수·조건문·반복문·자료구조가 있으며, 클래스 적용은 후속 구현 과제입니다.
- **확장 활용:** 공공데이터/오픈 API, 데이터 분석·시각화, 파일 처리/경량 DB, 대화형 인터페이스 중 하나 이상이 필요합니다. 현재 CSV 파일 처리와 `pandas` 데이터 분석을 사용합니다.
- **역할:** 제출 보고서에 팀원별 구체적인 작업을 명시해야 합니다.

- **제출 형태:** Python 소스코드(`.py`/`.ipynb`) 또는 Streamlit 앱을 사용할 수 있습니다.
